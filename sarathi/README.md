# Сарати

Сайт помощника по ведическим писаниям, который знает карту рождения: ведический
гороскоп дня, совместимость пары и диалог с наставником — всё вокруг карты
человека, а не вокруг «знака месяца».

Это статический сайт без сборки и без сервера: HTML, CSS и обычные `<script>`.
Никаких зависимостей, никакого npm-билда. Все расчёты идут в браузере
посетителя, введённые данные рождения никуда не уходят.

## Быстрый старт

```bash
# любой статический сервер
npx http-server -p 8080 -c-1 .
# открыть http://127.0.0.1:8080
```

Файл `index.html` открывается и просто двойным щелчком (`file://`) — скрипты
обычные, модулей и `fetch` нет. Локальный сервер нужен только для тестов.

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: герой с живым «небом прямо сейчас», три опоры помощника, стих дня, пример диалога, как это работает, платформа, вопросы |
| `chart.html` | Карта рождения + небо дня: грахи, бхавы, накшатры, панчанга, мухурта, транзиты, Вимшоттари-даша, стих |

| `dialog.html` | Диалог с Сарати: ответы собираются из карты собеседника и неба дня |

## Что здесь настоящее, а что демонстрация

Честно, чтобы никого не вводить в заблуждение:

**Настоящее** — весь астрономический и джйотиш-расчёт. Положения грах, лагна,
бхавы, накшатры с падами, панчанга, восход и закат, отрезки мухурты,
Вимшоттари-даша, Аштакута. Это не заглушки: цифры считаются по классическим
алгоритмам и проверены против внешней эфемериды (см. «Точность»).

**Демонстрация** — диалог на `dialog.html`. Языковая модель не подключена:
ответы собираются из карты и неба дня по правилам, поэтому они действительно
разные у разных людей, но их набор конечен. На странице об этом сказано прямо.
«Память бесед» — настоящая, но скромная: история тем лежит в `localStorage`.

**Заглушки** — разделы платформы (курсы, тренажёр ума, семейное древо, хинди,
школы) и тарифы с мудрами: на главной они описаны, но страниц под ними пока нет.

## Метод расчёта

- Сидерический (нираяна) зодиак, аянамша **Лахири** (читрапакша).
- Бхавы — **целыми раши** (раши-бхава): первая бхава — весь раши лагны.
  Так рисуют и северную, и южную карту, и это снимает спор о системах домов.
- Раху и Кету — **средние** узлы Луны.
- Положения видимые: с нутацией в долготе и годичной аберрацией.
- Время: `TT` из `UT` через ΔT (полиномы Эспенака — Меуса).
- Часовой пояс места рождения берётся из базы IANA внутри браузера (ICU), то
  есть с полной историей декретного и летнего времени. Для Москвы 1975 года
  получится UTC+3, для 1985 летом — UTC+4, для 2012 — UTC+4 круглый год.
  Это одна из самых частых ошибок в самодельных калькуляторах карт.

### Точность

Проверено против `pyephem` (libastro: VSOP87 + ELP2000) на 1176 датах с 1930 по
2050 год — `test/validate_ephemeris.py`:

| Граха | Макс. ошибка | СКО |
|---|---|---|
| Луна | 14″ | 3,4″ |
| Солнце | 35″ | 12,3″ |
| Меркурий | 94″ | 21″ |
| Венера | 177″ | 25″ |
| Марс | 205″ | 35″ |
| Юпитер | 113″ | 31″ |
| Сатурн | 173″ | 58″ |

Для сравнения: пада накшатры — 3°20′, то есть 12 000″. Ошибка в 3,5′ имеет
значение только у самой границы раши или накшатры.

Формула лагны отдельно сверена с прямым перебором по горизонту на семи местах
от экватора до 69° с. ш. — расхождение не больше 1,4″ (`test/check_ascendant.mjs`).
Восход и закат совпадают с `pyephem` с точностью до секунды.

Аянамша Лахири приближена накопленной общей прецессией (IAU 2006) с привязкой
23°51′11″ на J2000. От опубликованных таблиц Лахири это отличается на десятки
угловых секунд — величина, невидимая на уровне раши, накшатры и пады.

### Где модель упрощена (и это написано на самих страницах)

- **Вашья и йони** в Аштакуте: источники расходятся в деталях, взята упрощённая
  симметричная матрица. Остальные шесть кут — по общепринятым таблицам.
- **Сожжение (астангата)** считается по умеренным общепринятым границам, без
  отдельных правил для ретроградных планет.
- Вимшоттари-год — 365,2425 суток (как в большинстве современных программ).

## Тексты писаний

Стихи в `assets/js/data/verses.js` даны в транслитерации IAST, перевод —
**смысловой, сделанный для этого сайта**: это не перепечатка какого-либо
изданного перевода. Перед публикацией сверьте нумерацию и текст с печатным
изданием — так поступают с любой цитатой из писания.

Стих дня выбирается не случайно: по хозяину вары, хозяину накшатры Луны и фазе
Луны собирается круг подходящих стихов, а дата выбирает внутри него. Под стихом
всегда видно, почему выбран именно он.

## Тесты

```bash
./test/run_all.sh
```

Модульные тесты и проверка лагны работают на голом `node`. Сверка с `pyephem`
включается, если установлен модуль (`pip install ephem`), проверка страниц — если
есть `playwright`. Оба шага пропускаются молча, а не роняют прогон.

## Правки, которые понадобятся первыми

- **Название сайта.** Встречается в `<title>`, логотипе, подвале и в тексте
  героя. Замена — поиском по «Сарати» (имя наставника в текстах диалога менять
  не нужно, если платформа переименуется).
- **Города.** `assets/js/data/cities.js`, формат `[название, широта, долгота,
  зона IANA, регион]`. Долгота восточная положительная.
- **Стихи.** `assets/js/data/verses.js`, поле `themes` связывает стих с небом дня.
- **Темы диалога.** Массив `TOPICS` в `assets/js/ui/dialog-page.js`.
- **Цвета и типографика.** Переменные в `:root` в `assets/css/base.css`. Тема
  тёмная; светлая добавляется переопределением тех же переменных.

## Ограничения

- Шрифты подгружаются с Google Fonts; без сети сайт откатывается на системные
  Georgia и системный гротеск — вёрстка не ломается.
- Лагна не считается выше 89,5° широты: горизонт там пересекает эклиптику не
  обычным образом. Форма скажет об этом словами, а не молча выдаст чушь.
- Диапазон дат расчёта — 1800–2200 (форма ограничивает 1900–2100).
