# Как это запустить

Инструкция для человека, который раньше серверов не поднимал. Если что-то
покажется очевидным — пропускайте, я старался ничего не пропустить.

Всё, что тут написано, делается на обычном ноутбуке за полчаса.

---

## Шаг 0. Что вообще есть в проекте

Три части, и они работают независимо:

| Часть | Что делает | Нужен ли сервер |
|---|---|---|
| **Сайт** | карта, день, совместимость, мухурта, ректификация | нет, это обычные файлы |
| **Бот** | утренняя сводка, день, даша, дневник в телеграме | да, где-то должен работать `node` |
| **API** | проверяет оплату и отдаёт платные разборы | да, тот же процесс что и бот |

Сайт можно выложить прямо сейчас и он будет работать без всего остального.
Бот и API нужны, когда дойдёт до денег и рассылки.

---

## Шаг 1. Поставить Node.js

Это программа, которая умеет запускать наш код. Нужна версия **20 или новее**.

- **Windows и macOS:** откройте <https://nodejs.org>, скачайте кнопку «LTS»,
  установите, соглашаясь со всем по умолчанию.
- **Linux (Ubuntu, Debian):** в терминале

  ```bash
  sudo apt update && sudo apt install -y nodejs npm
  ```

Проверьте, что получилось. Откройте терминал (на Windows — «PowerShell»)
и напишите:

```bash
node -v
```

Должно ответить чем-то вроде `v22.11.0`. Если ответило `команда не найдена` —
Node не установился, попробуйте ещё раз или перезапустите терминал.

## Шаг 2. Запустить сайт у себя

Перейдите в папку проекта и запустите:

```bash
cd путь/к/aruna
node server/api.js
```

Увидите:

```
Аруна · сайт и API на http://127.0.0.1:8080
```

Откройте <http://127.0.0.1:8080> в браузере — сайт работает.
Остановить: `Ctrl+C` в терминале.

> Если порт 8080 занят: `PORT=3000 node server/api.js`

## Шаг 3. Завести телеграм-бота

1. Откройте Telegram и найдите **@BotFather** (у него синяя галочка).
2. Напишите ему `/newbot`.
3. Он спросит **имя** бота — это то, что видят люди. Например: `Аруна`.
4. Потом спросит **адрес** — должен заканчиваться на `bot`. Например: `aruna_jyotish_bot`.
   Если адрес занят, он скажет, придумайте другой.
5. В ответ придёт сообщение со строкой вида:

   ```
   8123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```

   **Это токен. Он как пароль — не показывайте его никому и не выкладывайте
   в интернет.**

### Куда его положить

Создайте файл `server/config.json` рядом с `server/bot.js`:

```json
{
  "botToken": "8123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw",
  "site": "https://ваш-сайт.ru"
}
```

`site` можно оставить пустым, если сайта ещё нет.

> **Важно:** этот файл уже добавлен в `.gitignore`, то есть он не попадёт
> в git и не утечёт. Не переносите токен в другие файлы.

Проверьте, что токен рабочий:

```bash
node server/bot.js --check
```

Ответит: `Токен рабочий. Бот: @ваш_бот`.

## Шаг 4. Запустить всё вместе

```bash
node server/index.js
```

Эта команда поднимает сайт, API и бота одним процессом — и связывает их,
чтобы вход на сайт можно было подтверждать через бота.

Теперь найдите своего бота в Telegram, напишите `/start` и пройдите
три вопроса: дата, время, город. Дальше работают `/today`, `/muhurta`,
`/dasha`, `/sav`.

Включите утреннюю сводку командой `/digest` — бот будет писать около
7 утра по вашему часовому поясу.

## Шаг 5. Чтобы работало круглосуточно

Пока терминал открыт, бот живёт. Закроете — умрёт. Варианты:

### Вариант А: самый простой — арендовать сервер

Возьмите самый дешёвый VPS (Timeweb, Selectel, Beget — от 200 ₽ в месяц,
подойдёт машина с 1 ГБ памяти). Подключитесь к нему по SSH, поставьте Node
как в шаге 1, скопируйте папку проекта и настройте автозапуск:

```bash
sudo nano /etc/systemd/system/aruna.service
```

Вставьте (поправьте пути и имя пользователя):

```ini
[Unit]
Description=Aruna
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/aruna
ExecStart=/usr/bin/node /opt/aruna/server/index.js
Restart=always
RestartSec=5
Environment=PORT=8080

[Install]
WantedBy=multi-user.target
```

Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`) и включите:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now aruna
sudo systemctl status aruna      # посмотреть, что живёт
sudo journalctl -u aruna -f      # посмотреть логи
```

Теперь бот переживёт перезагрузку сервера и сам поднимется, если упадёт.

### Вариант Б: только сайт, без бота

Сайт — это статические файлы, его можно положить бесплатно:

- **GitHub Pages** — в настройках репозитория включить Pages и указать папку;
- **Netlify** или **Cloudflare Pages** — перетащить папку в браузер, готово.

Бот и платные разборы при этом работать не будут, но карта, день,
совместимость, мухурта и ректификация — да, потому что считаются в браузере.

## Шаг 6. Когда дойдёт до денег

Сейчас включён демонстрационный режим: биджи начисляются бесплатно.
Переключатель — в файле `assets/js/core/access.js`, первая строка кода:

```js
var DEMO = true;      // поставить false, когда подключите оплату
```

Пока `DEMO = true`, кнопка пополнения просто добавляет биджи. Когда
поставите `false`, сервер начнёт отвечать «приём оплаты ещё не подключён» —
это сигнал, что пора вставить платёжного провайдера.

### Что нужно сделать для настоящей оплаты

1. Завести счёт у провайдера: **ЮKassa** или **CloudPayments** (оба работают
   с картами и СБП, для самозанятых и ИП подключение простое).
2. В файле `server/api.js` найти строку с комментарием
   «Здесь будет создание платежа у провайдера».
3. Заменить её на создание платежа по документации провайдера и добавить
   обработчик webhook — он приходит, когда деньги списались, и должен
   увеличить `w.balance`.

Всё остальное уже готово: списания, проверка права на разбор, подписка.

## Шаг 7. Проверить, что ничего не сломалось

```bash
./test/run_all.sh
```

Прогоняет всё: расчёты, бота, API и страницы в браузере. Если где-то
появится красное — значит правка что-то задела.

Отдельные проверки, если нужно быстро:

```bash
node test/unit.mjs        # расчёты
node test/bot.test.js     # бот
node test/api.test.js     # сервер и оплата
```

## Если что-то не работает

**«команда не найдена: node»** — Node не установлен или терминал открыт
до установки. Закройте терминал, откройте заново.

**«EADDRINUSE: address already in use»** — порт занят другой программой.
Запустите с другим портом: `PORT=3000 node server/index.js`.

**Бот не отвечает** — проверьте токен: `node server/bot.js --check`.
Если пишет про сеть, возможно, у провайдера закрыт доступ к `api.telegram.org`;
на российских серверах это бывает, помогает сервер за пределами РФ.

**Бот отвечает, но молчит утром** — сводка приходит, только если включить её
командой `/digest`, и только если процесс работает в тот час.

**Сайт открывается, но кнопки платных разборов не работают** — так и есть
без сервера: откройте сайт не файлом, а через `node server/api.js`.

**Данные пропали** — всё лежит в `server/data/*.json`, это обычные текстовые
файлы. Их стоит иногда копировать в надёжное место: это единственное, что
нельзя восстановить из кода.

## Что стоит сделать в первую очередь

1. Запустить у себя (шаги 1–4) и полчаса поиграть с ботом.
2. Показать трём знакомым и послушать, что непонятно.
3. Только потом — сервер, домен и оплата.

Обратный порядок — самый частый способ потратить месяц на инфраструктуру
для продукта, который ещё никто не видел.
